# Lekcja 36 — AWS i infrastruktura

Z katalogu głównego kursu uruchom:

```powershell
.venv/Scripts/python.exe lessons/lesson36/run_app.py
```

Aplikacja jest dostępna pod adresem http://127.0.0.1:8036/. W razie braku zależności zainstaluj je z `lessons/lesson36/requirements.txt`.

Każde z 20 zadań ma własny katalog `examples/taskXX`. We wstępie zobaczysz, co zrobi pokaz. W zakładce **Obserwuj działanie** uruchomisz przykład, a w **Zrozum kod** możesz najechać na numer wiersza, nazwę lub blok kodu i przypiąć objaśnienie kliknięciem.

Pokazy uruchamiają modele usług i przykłady z podstawionym klientem AWS. Zadanie 20 pokazuje plan zależności oraz miejsce na procedury tworzące zasoby. Wybrane zadania zawierają oddzielne funkcje korzystające z API AWS po podaniu klienta.
