# Lekcja 28 — projekty

- [Treść lekcji](lesson-28.md) — dokumentacja API w Django REST Framework.
- [API Lab](api_lab/README.md) — osobny projekt z ośmioma interaktywnymi przykładami
  wykorzystującymi kod z treści lekcji. Wstęp, zastosowania, kroki, kod i pytania;
  działające API, Swagger UI i ReDoc. Domyślny port: 8028.
- `l28_pro/` — istniejący projekt GameShelf.

Uruchom API Lab z katalogu kursu:

```powershell
.venv\Scripts\python.exe lessons\lesson28\api_lab\run_app.py
```

Projekty mają oddzielne katalogi i bazy. Instrukcje przygotowania środowiska
oraz lista przykładów znajdują się w README API Lab.
