# Lekcja 38 — CI/CD i GitHub Actions

Z katalogu głównego kursu uruchom:

```powershell
.venv/Scripts/python.exe lessons/lesson38/run_app.py
```

Aplikacja jest dostępna pod adresem http://127.0.0.1:8038/. W razie braku zależności zainstaluj je z `lessons/lesson38/requirements.txt`.

Każde z 20 zadań ma własny katalog `examples/taskXX`. We wstępie zobaczysz, co zrobi pokaz. W zakładce **Obserwuj działanie** uruchomisz przykład, a w **Zrozum kod** możesz najechać na numer wiersza, nazwę lub blok kodu i przypiąć objaśnienie kliknięciem.

Pliki workflow znajdują się wewnątrz katalogów zadań. Aby uruchomić je na GitHubie, użyj katalogu danego zadania jako osobnego repozytorium ćwiczeniowego i uzupełnij wymagane zmienne oraz sekrety. Pokazy lokalne używają danych przykładowych i uruchamiają testy tam, gdzie są częścią zadania. W zadaniu 18 macierz ma 9 kombinacji przed wykluczeniem i 8 po nim.
